# ContractSentinel API (Day 1 MVP)

## Run on Windows PowerShell
```powershell
cd backend
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```
Open http://127.0.0.1:8000/docs and check `/api/health`.

### Implemented today
- PDF text extraction for text-based PDFs using PyMuPDF.
- Baseline rule-assisted clause segmentation and categorization.
- Policy lookup against a small built-in playbook.
- Transparent heuristic risk flags and template redline suggestions.
- LangGraph workflow graph when LangGraph installs successfully.
- JSON persistence of reviews and approve/reject decisions.
- Graph nodes/edges returned for the frontend.

### Known limitations
- No OCR for scanned PDFs yet.
- Day 1 classifier is a transparent keyword baseline, NOT the planned trained TF-IDF/SVM model.
- Policy retrieval is category/keyword based, not yet embedding-based Graph RAG.
- Redlines are templates, not generated by an LLM.
- This is an educational prototype, not legal advice.
